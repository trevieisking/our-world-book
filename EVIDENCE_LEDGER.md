# EVIDENCE LEDGER

This is the claim-control register for **Our World**.

## Rules
- Record claims that materially affect the historical/scientific narrative.
- Prefer primary research, high-quality reviews, scientific agencies, museum/geological collections, archaeological reports and critical historical scholarship.
- Never upgrade uncertainty merely because a reconstruction is visually persuasive.
- A source supporting one part of a story does not automatically support every adjacent claim.
- "Not established" is not the same as "proved impossible."
- Record conflicting evidence rather than hiding it.
